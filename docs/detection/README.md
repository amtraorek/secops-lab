# Detección

## Descripción

Este directorio documenta las reglas de detección, decoders y configuraciones de alertas implementadas en Wazuh para la infraestructura de CoreLab.

## Estado actual

* Utilización de reglas y decoders estándar de Wazuh.
* En proceso de afinado y creación de reglas personalizadas orientadas a los servicios específicos de CoreLab.

## Estructura de documentación

A medida que se implementen reglas de detección específicas, se documentarán en esta sección detallando:
* ID y nombre de la regla.
* Objetivo de detección.
* Nivel de severidad.
* Evidencia de funcionamiento y alertas generadas.
