# Incidentes

## Descripción

Registro de análisis e investigación de alertas y eventos notables detectados en el laboratorio durante la operación normal o pruebas de seguridad controladas.

## Estructura de un caso de incidente

Cada caso documentado incluye:
1. **Fecha y hora**
2. **Objetivo / Contexto**
3. **Técnica o actividad observada**
4. **Alertas generadas en Wazuh**
5. **Análisis e investigación**
6. **Conclusiones**
7. **Medidas de mitigación o mejora aplicadas**
